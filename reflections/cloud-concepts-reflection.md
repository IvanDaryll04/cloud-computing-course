# Cloud Concepts Reflection

Cloud computing has become part of my daily life because many of the applications I use rely on cloud technology. Three cloud services I regularly use are **Google Drive, Netflix, and Messenger**. These applications demonstrate how cloud computing makes digital services accessible, convenient, and scalable.

**Google Drive** is a **Software as a Service (SaaS)** application because users can directly access tools for storing, creating, and managing files without managing the underlying infrastructure. It uses a **Public Cloud** deployment model because its services are hosted by a cloud provider and are accessible to users through the internet. **Netflix** is also **SaaS** because users access its streaming service without managing servers or software infrastructure. It uses a **Public Cloud** model because its services are delivered through internet-based cloud infrastructure to a large number of customers. **Messenger** is another example of **SaaS**, since users simply use the application to communicate while the provider manages the servers, networking, and other infrastructure. It also follows a **Public Cloud** deployment model because the service is available to users over the internet.

Git and GitHub are also important when working with cloud projects. **Version control is critical** because cloud infrastructure configurations, scripts, and application code can change frequently. Git allows developers to record changes, compare previous versions, and restore working configurations when errors occur. This helps reduce the risk of losing important work or accidentally introducing problems.

**GitHub** further improves collaboration by allowing team members to share repositories, review changes, manage branches, and work on different parts of a project without overwriting each other's work. It also provides a history of changes, making it easier to identify who made a change and why. Overall, I learned that cloud computing is not only about accessing services online; it also requires proper organization, collaboration, and version control. Git and GitHub provide essential tools for managing cloud-related projects efficiently and safely.
