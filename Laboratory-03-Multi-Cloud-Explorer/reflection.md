# Reflection

Throughout this mission, I explored the major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Among the three, AWS impressed me the most because of its wide range of services and flexible options for different types of workloads. I learned that AWS can support startups, large enterprises, web applications, databases, storage, and many other cloud computing requirements.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, object storage, databases, networking, identity and access management, Kubernetes, security features, and scalable cloud infrastructure. They also use a similar model where organizations can access computing resources over the internet instead of maintaining all physical infrastructure themselves. However, each platform has different strengths and services that can make it more suitable for specific requirements.

Business requirements have a major influence on cloud platform selection. Factors such as budget, existing technologies, performance requirements, scalability, security, geographic availability, and business goals must be considered before choosing a provider. For example, Azure is a strong choice for organizations that already use Microsoft technologies, while GCP can be suitable for companies focused on artificial intelligence, machine learning, data analytics, and Kubernetes.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I need to understand the client's requirements first and then match those requirements with the appropriate cloud services. This activity improved my ability to analyze scenarios and recommend practical cloud solutions.

My GitHub Cloud Computing Portfolio also improved significantly after completing this mission. I learned how to organize research, comparison tables, recommendations, Linux investigations, and reflections using Markdown files. More importantly, the portfolio now demonstrates my understanding of multiple cloud platforms and my ability to apply cloud computing concepts to real-world business situations.
