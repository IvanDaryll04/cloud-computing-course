# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, security, and application development. Google Cloud uses Google's global infrastructure to provide scalable and reliable cloud services.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of regions and zones. Regions represent geographic locations where cloud resources can be deployed, while zones are isolated locations within regions. Google Cloud also operates a global network designed to provide reliable connectivity and reduce latency for users around the world.

Google Cloud provides infrastructure and connectivity across more than 200 countries and territories.

## Cloud Management Console

The Google Cloud Console is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources. Users can manage virtual machines, storage, databases, networking, security, Kubernetes clusters, and other cloud services through the console.

## Four (4) Core Services

### 1. Compute Engine

Google Compute Engine provides virtual machines that allow organizations to run applications and workloads using Google's cloud infrastructure.

### 2. Cloud Storage

Google Cloud Storage is an object storage service used to store and retrieve data such as files, backups, media, and application data.

### 3. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service that allows organizations to deploy, manage, and scale containerized applications.

### 4. BigQuery

BigQuery is a fully managed and serverless data warehouse designed for analyzing large datasets using SQL and other analytical tools.

## Three (3) Advantages

1. **High-Performance Global Network** – Google Cloud uses Google's global network infrastructure to provide reliable and efficient connectivity.
2. **Strong Data and Analytics Services** – Services such as BigQuery provide powerful tools for processing and analyzing large amounts of data.
3. **Scalability** – Google Cloud allows organizations to scale computing, storage, databases, and other resources according to their workload requirements.

## Typical Enterprise Use Cases

Enterprises commonly use Google Cloud for web and application hosting, data analytics, artificial intelligence and machine learning, containerized applications, database management, data storage, and large-scale data processing. Organizations can also use Google Kubernetes Engine to deploy and manage containerized enterprise applications.
