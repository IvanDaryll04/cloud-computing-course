# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, databases, networking, analytics, artificial intelligence, security, and application development. Azure enables organizations to build, deploy, manage, and scale applications using Microsoft's global cloud infrastructure.

## Global Infrastructure

Azure provides a global infrastructure made up of regions, datacenters, and availability zones. An Azure region consists of one or more datacenters connected through a high-capacity, fault-tolerant, low-latency network. Azure regions are organized across different geographic areas and provide options for data residency, compliance, disaster recovery, and application resiliency.

Microsoft currently states that Azure provides more than 70 regions globally.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Administrators and developers can use the portal to manage virtual machines, databases, storage, networking, security, applications, and other cloud services.

## Four (4) Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides virtualized computing resources that allow organizations to run applications and operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, backups, and application data.

### 3. Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL Server technology. It provides database capabilities without requiring organizations to manage the underlying infrastructure.

### 4. Azure Functions

Azure Functions is a serverless computing service that allows developers to execute code in response to events without managing physical or virtual servers.

## Three (3) Advantages

1. **Integration with Microsoft Technologies** – Azure works well with Microsoft products and technologies such as Windows Server, SQL Server, Microsoft 365, and other enterprise solutions.
2. **Global Infrastructure** – Azure provides regions across many geographic locations, allowing organizations to deploy applications closer to their users.
3. **Enterprise and Hybrid Cloud Support** – Azure provides services that support enterprise environments and hybrid cloud architectures that combine on-premises infrastructure with cloud resources.

## Typical Enterprise Use Cases

Enterprises commonly use Azure for application hosting, virtual machines, database management, data analytics, artificial intelligence, backup and disaster recovery, software development, and hybrid cloud deployments. Azure is also frequently used by organizations that already depend on Microsoft technologies.
